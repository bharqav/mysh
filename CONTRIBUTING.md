# Contributing

Thanks for contributing to mysh.

## Development setup

1. Install dependencies (`g++`, `make`, `bash`, optional `libreadline-dev`).
2. Build with `make`.
3. Run checks with `make check`.
4. Run lint with `make lint`.

## Pull request requirements

- Keep changes scoped and focused.
- Add or update tests for behavior changes.
- Ensure `make check` passes locally.
- Update docs when user-visible behavior changes.

## Commit guidelines

- Use descriptive commit messages.
- Prefer small, reviewable commits.
- Do not mix unrelated refactors with bug fixes.

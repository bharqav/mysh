# Security Policy

## Supported versions

This project is currently maintained on the default branch only.

## Reporting a vulnerability

If you discover a security issue, please do not open a public issue with exploit details.

Instead:

1. Share a private report with:
   - impact summary
   - reproduction steps
   - affected version/commit
   - suggested fix (optional)
2. Expect acknowledgement within 72 hours.

## Scope notes

`mysh` is an educational shell and not intended for privileged command execution environments.
Do not run it as root in untrusted multi-user systems.
